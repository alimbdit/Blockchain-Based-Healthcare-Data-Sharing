HEALTHCHAIN DAPP - COMMAND CHEATSHEET FOR SEPARATE TERMINALS
================================================================================

Ensure you are inside the project directory:
cd "/home/md-abdul-alim/Documents/MSc/2nd_semester/BLOCK CHAIN/Assignment/p01"

--------------------------------------------------------------------------------
TERMINAL 1: START LOCAL BLOCKCHAIN NODE
--------------------------------------------------------------------------------
# Starts the local Ethereum JSON-RPC node on http://127.0.0.1:8545 with Chain ID 31337
# Keep this terminal open and running!

npx hardhat --config hardhat.config.cjs node


--------------------------------------------------------------------------------
TERMINAL 2: DEPLOY SMART CONTRACT & SEED DEMO DATA
--------------------------------------------------------------------------------
# Deploys HealthcareDataSharing.sol to the running local node
# Seeds initial profiles (Alice, Bob, Dr. Smith, Dr. Patel, Metro Hospital)
# Generates src/contracts/contractData.json for the frontend

npx hardhat --config hardhat.config.cjs run scripts/deploy.js --network localhost


--------------------------------------------------------------------------------
TERMINAL 3: START FRONTEND WEB APPLICATION (VITE + REACT)
--------------------------------------------------------------------------------
# Starts the frontend development server
# Open browser at: http://localhost:5173

npm run dev


--------------------------------------------------------------------------------
TERMINAL 4 (OPTIONAL): RUN TESTS & FULL PERFORMANCE BENCHMARK
--------------------------------------------------------------------------------
# Run the 14 automated unit tests verifying all assignment requirements:
npm test

# Run the CLI performance benchmark engine (measures gas, latencies, AES throughput, TPS):
npm run benchmark

# Build the production bundle:
npm run build
